Рядом с часами Pulse в реальном времени показывает загрузку CPU, занятую память и скорость сети. По клику выпадает панель с графиками и подробностями.

## Что показывает

- **Процессор**: общая загрузка (пользователь и система отдельно), график за последние минуты, загрузка каждого ядра с пометкой E/P (энергоэффективные и производительные ядра Apple Silicon), средняя нагрузка.
- **Память**: использование в тех же категориях, что в Мониторинге системы (приложения, ядро, сжатая, кэш), давление памяти, файл подкачки.
- **Сеть**: скорость загрузки и отдачи с графиками, трафик с момента запуска, интерфейс и IP-адрес.
- **Видеочип**: загрузка GPU.
- **Диск**: свободное место на пользовательском томе.
- **Аккумулятор**: заряд, время до разряда или полной зарядки, состояние (health), число циклов, температура, мощность адаптера.
- **Процессы**: топ по CPU или по памяти, с иконками приложений.
- **Температурное состояние**: предупреждение, если macOS начала троттлить процессор.

## Архитектура

```
src/
├── core/Metrics            # чистая логика: дельты CPU, скорость по счётчикам, форматирование (тесты)
├── platform/
│   ├── Probe_mac.mm        # host_processor_info, host_statistics64, sysctl, NET_RT_IFLIST2,
│   │                       # IOPowerSources, AppleSmartBattery, IOAccelerator, libproc
│   └── Native_mac.mm       # NSStatusItem, всплывающая панель, SMAppService
├── app/
│   ├── SystemMonitor       # опрос по таймеру, история, свойства для QML
│   ├── MenuBarRenderer     # рисует строку меню через QPainter
│   ├── ProcessIcons        # иконки приложений для QML
│   └── AppController       # настройки, статус-бар, позиционирование панели
qml/                        # панель: карточки, графики на QtQuick.Shapes, настройки
tests/                      # Qt Test
```

Решения, которые стоит отметить:

- **Два режима опроса.** Пока панель закрыта, читается только то, что нужно для строки меню. Процессы, детали аккумулятора и диск опрашиваются только при открытой панели, поэтому в фоне приложение почти не тратит CPU.
- **Свой NSStatusItem.** `QSystemTrayIcon` умеет показывать только квадратную иконку, а здесь нужен элемент переменной ширины с живыми цифрами. Картинка рисуется `QPainter`'ом как template image, поэтому macOS сама перекрашивает её под светлую или тёмную строку меню. Цифры моноширинные (`tnum`), чтобы элемент не дёргался при обновлении.
- **64-битные сетевые счётчики** через `NET_RT_IFLIST2`: у `getifaddrs` счётчики 32-битные и переполняются каждые 4 ГБ. Считаются только физические интерфейсы (`en*`), иначе трафик через VPN учитывался бы дважды.
- **CPU процессов на Apple Silicon.** `proc_pidinfo` отдаёт время в тиках Mach, а не в наносекундах, поэтому оно пересчитывается через `mach_timebase_info`. Без этого значения были бы завышены примерно в 41 раз.
- **Память как в Мониторинге системы**: «использовано» = app + wired + compressed, а для процессов берётся `phys_footprint`.

## Сборка

```bash
brew install qt cmake ninja

# разработка
cmake -S . -B build -G Ninja -DCMAKE_PREFIX_PATH="$(brew --prefix qt)"
cmake --build build && ctest --test-dir build
./build/Pulse.app/Contents/MacOS/Pulse

# готовое приложение + .dmg (+ установка в /Applications)
./scripts/package.sh --install
```

Нужна macOS 13+ и Apple Silicon или Intel. Никаких специальных разрешений приложению не требуется.
